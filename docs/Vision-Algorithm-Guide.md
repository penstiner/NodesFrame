## 一、基础预处理

### 1. 高斯模糊（GaussianBlur）

| 属性 | 说明 |
|------|------|
| 节点名 | 高斯模糊 |
| 参数 | `kernelSize` 核大小（≥3，自动补齐奇数）、`sigmaX` 标准差 |
| 默认值 | k=3, σ=1 |

**使用场景**：消除高斯噪声、平滑图像、为边缘检测做预处理。

**调参技巧**：
- 核越大模糊越强，但计算量增大。一般 `3~9` 即可。
- `sigmaX=0` 时由核大小自动计算；手动设置 >1 加强模糊。
- **边缘检测前**宜用小核（k=3），否则边缘被抹除。

---

### 2. 中值滤波（MedianBlur）

| 属性 | 说明 |
|------|------|
| 节点名 | 中值滤波 |
| 参数 | `ksize` 核大小（≥3，自动补齐奇数） |
| 默认值 | k=3 |

**使用场景**：**椒盐噪声**的去除效果远优于高斯模糊，常用于工业相机传感器的离散噪点清理。

**调参技巧**：
- 去椒盐噪声用 k=3~5，太大则细节丢失。
- **不适用于高斯噪声**——高斯噪声用高斯模糊。
- 每次只增加 2（3→5→7），逐步测试。

---

### 3. 双边滤波（BilateralFilter）

| 属性 | 说明 |
|------|------|
| 节点名 | 双边滤波 |
| 参数 | `d` 滤波直径、`sigmaColor` 色彩标准差、`sigmaSpace` 空间标准差 |
| 默认值 | d=9, σColor=75, σSpace=75 |

**使用场景**：**保边去噪**（美颜效果），在去除平坦区域噪声的同时保留物体边缘清晰度。适合人脸、产品外观检测。

**调参技巧**：
- `sigmaColor` 越大，颜色跨度大的区域也会被平滑 → 边缘模糊。
- `sigmaSpace` 越大，空间距离远的像素也参与平滑 → 更模糊。
- **美颜效果**：d=9, σColor=75, σSpace=75。
- **工业检测**：d=5, σColor=50, σSpace=50 保留更多细节。
- 速度较慢，大图建议先缩放再处理。

---

### 4. 亮度对比度（BrightnessContrast）

| 属性 | 说明 |
|------|------|
| 节点名 | 亮度对比度 |
| 参数 | `alpha` 对比度系数、`beta` 亮度增量 |
| 默认值 | α=1.0, β=0 |
| 公式 | `dst = alpha × 像素 + beta` |

**使用场景**：快速调整图像明暗和对比度，补偿光照不足或过曝。

**调参技巧**：
- `alpha=1.0` 保持不变；`>1` 增强对比度；`<1` 降低对比度（发灰）。
- `beta>0` 提亮；`beta<0` 变暗。
- 典型组合：`α=1.2, β=10`（轻微增强）；`α=1.5, β=30`（强增强）。

---

### 5. 伽马校正（GammaCorrection）

| 属性 | 说明 |
|------|------|
| 节点名 | 伽马校正 |
| 参数 | `gamma`（>0） |
| 默认值 | γ=1.0 |

**使用场景**：**非线性**亮度调整，补偿光照不均匀。γ<1 提亮暗区（同时保留亮部），γ>1 压暗过曝区。

**调参技巧**：
- `γ=0.5~0.8`：提亮暗部，适合逆光/阴影区域检测。
- `γ=1.5~2.2`：压暗过曝区，适合强光环境。
- `γ=1.0`：无变化。
- 与亮度对比度的区别：伽马校正是**非线性**的，暗部/亮部调整幅度不同。

---

### 6. 高斯噪声（GaussianNoise）

| 属性 | 说明 |
|------|------|
| 节点名 | 高斯噪声 |
| 参数 | `mean` 均值、`stddev` 标准差 |
| 默认值 | mean=0, stddev=25 |

**使用场景**：**测试用途**——模拟工业相机传感器噪声，验证算法鲁棒性。**不用于实际生产流程**。

**调参技巧**：
- `stddev=10~15`：轻微噪声，模拟良好光照环境。
- `stddev=25~40`：中等噪声，模拟一般工业环境。
- `stddev=50+`：强噪声，压力测试。
- 配合降噪算法（高斯模糊/中值滤波/双边滤波）验证抗噪能力。

## 二、色彩处理

### 7. 色彩转换（CvtColor）

| 属性 | 说明 |
|------|------|
| 节点名 | 色彩转换 |
| 参数 | `code` 转换模式 |
| 可选值 | BGR2GRAY / BGR2HSV / BGR2Lab / GRAY2BGR 等 |

**使用场景**：将 BGR 彩色图转为灰度、HSV、Lab 等色彩空间，为后续算法提供适配格式。

**调参技巧**：
- **边缘检测前** → 转 GRAY。
- **颜色提取前** → 转 HSV（InRange 节点内部已自动转换，无需手动转）。
- **Lab 空间**：L 通道与人类视觉一致，适合亮度均衡。

---

### 8. 颜色提取（InRange）

| 属性 | 说明 |
|------|------|
| 节点名 | 颜色提取 |
| 参数 | H(0~180), S(0~255), V(0~255) 各分量的最小值/最大值 |
| 默认值 | 全范围（无过滤） |

**使用场景**：从图像中提取特定颜色区域（红色零件、绿色指示灯、蓝色液体等）。

**调参技巧**：
- **查 HSV 表**：红 H≈0~10 ∪ 160~180；绿 H≈35~85；蓝 H≈100~130；黄 H≈20~35。
- **降低 S_min** 可捕捉浅色；**提高 S_min** 排除白色/灰色干扰。
- **降低 V_min** 可捕捉暗色；**提高 V_min** 排除阴影。
- 建议先用取色工具获取目标颜色 HSV，再设置 ±10 的容差范围。

---

### 9. 直方图均衡（EqualizeHist）

| 属性 | 说明 |
|------|------|
| 节点名 | 直方图均衡 |
| 参数 | 无 |

**使用场景**：**全局**对比度增强，适用于低对比度、灰蒙蒙的图像。

**调参技巧**：
- 仅支持灰度图（彩色图自动转灰）。
- **全局操作**，可能放大噪声——有噪声时先降噪再用。
- 光照不均匀场景优先用 **CLAHE**（见下文）而非本节点。

## 三、几何变换

### 10. 缩放（Resize）

| 属性 | 说明 |
|------|------|
| 节点名 | 缩放 |
| 参数 | 比例模式：`fx`/`fy`；尺寸模式：`width`/`height` |
| 默认值 | 比例模式，fx=fy=1.0 |

**使用场景**：缩小加速后续处理、放大查看细节、统一输入尺寸。

**调参技巧**：
- **缩小**用 `InterpolationFlags.Area`（抗锯齿最佳）。
- **放大**用 `InterpolationFlags.Cubic`（平滑）或 `Linear`（快速）。
- 保持纵横比：fx=fy 或等比例计算宽高。

---

### 11. 翻转（Flip）

| 属性 | 说明 |
|------|------|
| 节点名 | 图像翻转 |
| 参数 | `mode`：水平/垂直/双向 |

**使用场景**：镜像校正（摄像头倒装）、数据增强。

---

### 12. 旋转（Rotate）

| 属性 | 说明 |
|------|------|
| 节点名 | 图像旋转 |
| 参数 | `angle` 角度（顺时针）、`scale` 缩放 |
| 默认值 | angle=90°, scale=1.0 |

**使用场景**：校正倾斜工件、旋转后模板匹配。

**调参技巧**：
- 旋转后超出边界部分被裁剪，需配合缩放或扩大画布。

## 四、二值化

### 13. 全局二值化（Threshold）

| 属性 | 说明 |
|------|------|
| 节点名 | 二值化 |
| 参数 | `thresh` 阈值（0~255）、`maxval` 最大值、`type` 类型 |
| 默认值 | thresh=127, maxval=255, Binary |

**使用场景**：将灰度图转为黑白二值图，是形态学、连通区域、距离变换等算法的前置步骤。

**调参技巧**：
- 光照均匀 → 用 `Binary` + 手动阈值。
- 光照不均 → 用 `Binary | Otsu` 自动计算最优阈值。
- 暗背景亮目标 → 用 `BinaryInv`（反相二值化）。
- **阈值偏大**：目标断裂；**阈值偏小**：噪声变多。

---

### 14. 自适应二值化（AdaptiveThreshold）

| 属性 | 说明 |
|------|------|
| 节点名 | 自适应二值化 |
| 参数 | `blockSize` 邻域大小、`C` 修正值、`maxValue` |
| 默认值 | blockSize=11, C=2, maxValue=255 |

**使用场景**：**光照不均匀**场景的二值化，每个像素根据局部邻域计算阈值。优于全局二值化+Otsu。

**调参技巧**：
- `blockSize` 越大，局部区域越大，对光照不均匀的适应性越强（但计算变慢）。常用 11~21。
- `C` 为修正值，越大越"严苛"（更少像素变为白色）。正 C 抑制噪声。
- **文档/OCR 场景**：blockSize=11, C=2, 用 `Mean` 方法。
- **工业零件**：blockSize=15, C=5, 用 `Gaussian` 方法。

## 五、边缘检测

### 15. Canny 边缘（CannyEdge）

| 属性 | 说明 |
|------|------|
| 节点名 | Canny 边缘 |
| 参数 | `threshold1` 低阈值、`threshold2` 高阈值 |
| 默认值 | t1=50, t2=150 |

**使用场景**：**最常用的边缘检测算法**，提取图像中的物体轮廓。

**调参技巧**：
- **核心规则**：t2:t1 ≈ 2:1 或 3:1。
- 阈值越低 → 更多边缘（含噪声）；阈值越高 → 只保留强边缘。
- 标准起点：t1=50, t2=150；边缘太多 → 提高阈值；太少 → 降低阈值。
- **建议预处理**：先高斯模糊（k=3~5）去噪，再 Canny。

---

### 16. Sobel 边缘（SobelEdge）

| 属性 | 说明 |
|------|------|
| 节点名 | Sobel 边缘 |
| 参数 | `ksize` 核大小、`scale` 缩放 |
| 默认值 | k=3, scale=1.0 |

**使用场景**：一阶梯度边缘检测，突出 X 方向边缘。比 Canny 更"粗"，适合强调方向性边缘。

**调参技巧**：
- k=3 为标准 Sobel；k=5 为扩展 Scharr（更精确）。
- scale 越大边缘越亮。

---

### 17. Laplacian 边缘（LaplacianEdge）

| 属性 | 说明 |
|------|------|
| 节点名 | Laplacian 边缘 |
| 参数 | `ksize` 核大小、`scale` 缩放 |
| 默认值 | k=3, scale=1.0 |

**使用场景**：二阶微分检测，对噪声极度敏感。适合**已经去噪后**的精细边缘检测。对孤立点/细线响应强。

**调参技巧**：
- **必须先降噪**（高斯模糊/双边滤波），否则满屏噪点。
- ksize=1 时使用特殊核（更快但精度略低）。
- 与 Sobel 对比：Laplacian 对纹理/细线更敏感，Sobel 对方向边缘更敏感。

## 六、形态学操作

### 18. 形态学（MorphologyOp）

| 属性 | 说明 |
|------|------|
| 节点名 | 形态学 |
| 参数 | `op` 操作类型、`kernelSize` 核大小、`iterations` 迭代次数 |
| 可选操作 | Dilate（膨胀）、Erode（腐蚀）、Open（开运算）、Close（闭运算） |

**使用场景**：二值图像的后处理，消除噪点、连接断裂区域、分离粘连物体。

**调参技巧**：

| 操作 | 作用 | 场景 |
|------|------|------|
| **Erode**（腐蚀） | 缩小白色区域 | 去除细小噪点、分离粘连物体 |
| **Dilate**（膨胀） | 扩大白色区域 | 填充孔洞、连接断裂区域 |
| **Open**（开运算） | 先腐蚀再膨胀 | 去噪+保持主体大小不变 |
| **Close**（闭运算） | 先膨胀再腐蚀 | 填孔+保持主体大小不变 |

- `kernelSize` 决定操作范围：3=微小，5=中等，7+=大范围。
- `iterations` 可代替增大核（效果类似），但逐次迭代更可控。
- 典型流程：二值化 → 开运算（去噪）→ 闭运算（填孔）。

---

### 19. 形态学梯度（MorphGradient）

| 属性 | 说明 |
|------|------|
| 节点名 | 形态学梯度 |
| 参数 | `shape` 核形状、`kernelSize`、`iterations` |
| 公式 | `Gradient = Dilate - Erode` |

**使用场景**：快速提取物体**外轮廓**，比 Canny 更"粗壮"，适合二值图轮廓可视化。

**调参技巧**：
- 核越大 → 轮廓线越粗。
- 仅对二值图有意义。彩色图直接计算效果差。
- 形状选 `Ellipse` 可获更圆润轮廓。

## 七、图像增强

### 20. 图像锐化（Sharpen）

| 属性 | 说明 |
|------|------|
| 节点名 | 图像锐化 |
| 参数 | `strength` 锐化强度 |
| 默认值 | 1.5 |

**使用场景**：增强图像边缘和细节，让模糊图像变清晰。用于预处理以提高后续边缘检测/特征提取效果。

**调参技巧**：
- `strength=1.0~1.5`：轻度锐化，适合自然图像。
- `strength=2.0~3.0`：强锐化，适合文字/线条。
- **副作用**：锐化会放大噪声。建议锐化前先去噪（双边滤波后锐化效果最佳）。
- 公式本质：`dst = src + strength × (src - blurred)`。

---

### 21. CLAHE 均衡（CLAHE）

| 属性 | 说明 |
|------|------|
| 节点名 | CLAHE 均衡 |
| 参数 | `clipLimit` 对比度限制、`tileGridSize` 网格大小 |
| 默认值 | clipLimit=2, tileSize=8 |

**使用场景**：**局部**对比度增强，同时**抑制噪声放大**。优于全局直方图均衡。适合医疗影像、红外图像、光照不均的工业检测。

**调参技巧**：
- `clipLimit=1~3`：标准范围。越小越保守（接近原图）；越大对比度越强。
- `tileGridSize=4~8`：网格越小 → 局部性越强，但可能出现格状伪影。
- **推荐起点**：clipLimit=2.0, tileSize=8。
- 与 EqualizeHist 对比：CLAHE 是局部自适应，不会过度放大噪声。

## 八、特征检测

### 22. 霍夫直线（HoughLinesP）

| 属性 | 说明 |
|------|------|
| 节点名 | 霍夫直线 |
| 参数 | `rho` ρ分辨率、`theta` θ弧度、`threshold` 投票阈值、`minLineLength` 最小段长、`maxLineGap` 最大间隙 |
| 默认值 | ρ=1, θ=π/180, thresh=80, minLen=50, maxGap=10 |
| 输出 | 输出图像（标注直线）、**线段数**（Int32） |

**使用场景**：检测图像中的直线段（工件边缘、道路标线、条码边界等）。

**调参技巧**：
- ρ=1, θ=π/180（1度）为默认精度，一般不需要改。
- **threshold** 是最关键参数：越高 → 只检出强直线；越低 → 检出更多短小线段 + 噪声。
  - 长直线多：thresh=100~150。
  - 短线段多：thresh=30~60。
- `minLineLength`：小于此长度的线段被丢弃。增大可排除杂线。
- `maxLineGap`：允许的线段间断长度。增大可连接断裂的线段。
- **建议**：先用 Canny 边缘 → 再霍夫直线。

---

### 23. 霍夫圆检测（HoughCircles）

| 属性 | 说明 |
|------|------|
| 节点名 | 霍夫圆检测 |
| 参数 | `dp` 累加器分辨率、`minDist` 最小圆心距、`param1` Canny高阈值、`param2` 圆心阈值、`minRadius`/`maxRadius` |
| 默认值 | dp=1.5, minDist=50, p1=100, p2=60, minR=10, maxR=200 |
| 输出 | 输出图像（标注圆）、**圆数量**（Int32） |

**使用场景**：检测圆形目标——工业零件中的圆孔、螺丝、药片、硬币、细胞等。

**调参技巧**（按优先级排序）：
1. **`param2`（圆心阈值）**：越小检出越多圆（含误检），越大只检出强圆。起点 30~60。
2. **`param1`（Canny 高阈值）**：控制边缘检测强度。默认 100 通常合适。
3. **`minDist`**：两圆之间的最小距离（防止重复检测）。设为期望圆间距的 0.8 倍。
4. **`minRadius` / `maxRadius`**：设定预期半径范围，大幅减少误检。
5. **`dp`**：1=原图分辨率；2=半分辨率（更快但精度略降）。常用 1.2~1.5。

## 九、高级分析

### 24. 距离变换（DistanceTransform）

| 属性 | 说明 |
|------|------|
| 节点名 | 距离变换 |
| 参数 | `distanceType` 距离类型、`maskSize` 掩码尺寸 |

**使用场景**：计算二值图中每个前景像素到最近背景的距离。常用于：
- 分水岭分割的前景标记
- 物体中心定位
- 测量物体厚度

**调参技巧**：
- `L2`（欧氏距离）最精确；`L1`（曼哈顿）更快；`C`（棋盘）最快。
- 输出为灰度距离图，越亮越靠近物体中心。
- 输入必须是二值图（前景=白色 255）。

---

### 25. 连通区域（ConnectedComponents）

| 属性 | 说明 |
|------|------|
| 节点名 | 连通区域 |
| 参数 | 无 |
| 输出 | 输出图像（彩色染色）、**标签数**（Int32，含背景） |

**使用场景**：统计二值图中的独立物体数量、分析各个物体的大小和位置。如统计零件个数、缺陷个数。

**调参技巧**：
- 输入必须是二值图（需前置 Threshold 或 AdaptiveThreshold）。
- 噪声点会被计为一个区域 → 先做开运算去噪。
- 粘连物体会被计为一个区域 → 先用腐蚀分离或改用分水岭分割。

---

### 26. 模板匹配（TemplateMatch）

| 属性 | 说明 |
|------|------|
| 节点名 | 模板匹配 |
| 输入 | **2 个图像输入**：源图 + 模板图 |
| 参数 | `mode` 匹配方法 |
| 输出 | 输出图像（标注匹配位置）、**匹配分数**（Double） |

**使用场景**：在源图中定位模板图像的位置。用于工业定位（"这个零件在哪里"）、缺陷对齐、OCR 字符定位。

**调参技巧**：
- **`CcoeffNormed`**（归一化相关系数）：最推荐，分数 0~1，越高越匹配，对光照变化不敏感。
- **`SqDiffNormed`**（归一化平方差）：分数 0~1，越低越匹配。
- **`Ccoeff`**：无归一化，对光照敏感，仅用于固定光照场景。
- 分数阈值经验值：`CcoeffNormed` > 0.8 可认为匹配成功。
- 模板大小建议 20×20 以上，太小易误匹配。

---

### 27. 分水岭分割（Watershed）

| 属性 | 说明 |
|------|------|
| 节点名 | 分水岭分割 |
| 参数 | `fgThreshold` 前景阈值、`bgThreshold` 背景阈值 |
| 默认值 | fg=0.4, bg=0.3 |

**使用场景**：**分离粘连物体**——当连通区域无法分开时，用分水岭分割将接触的物体逐个分离。典型场景：堆叠的零件、粘连的细胞/颗粒。

**调参技巧**：
- **核心理念**：前景标记（确信是物体的区域）+ 背景标记（确信是背景的区域）→ 中间未知区域由算法自动分割。
- `fgThreshold`：越大 → 前景标记越严格（更少区域标记为前景），粘连物体更容易分离。常用 0.3~0.5。
- `bgThreshold`：越大 → 背景标记越严格。常用 0.2~0.4。
- **效果不好（欠分割）**：提高 fgThreshold → 让前景标记更分散。
- **效果不好（过分割）**：降低 fgThreshold → 让前景标记更集中。
- 输入建议经过去噪 + 二值化预处理。

## 十、几何校正与工具

### 28. 透视矫正（PerspectiveWarp）

| 属性 | 说明 |
|------|------|
| 节点名 | 透视矫正 |
| 参数 | 4 个源点坐标(x1,y1~x4,y4)、目标宽高(dstW, dstH) |
| 默认值 | 100×100 区域映射到 200×200 |

**使用场景**：校正拍摄角度造成的透视畸变，如将倾斜拍摄的矩形目标（卡片、屏幕、工件）"拉正"。

**调参技巧**：
- 源点顺序：左上 → 右上 → 右下 → 左下（顺时针）。
- 目标宽高比应与实际物体一致，否则矫正后图像拉伸。
- 需要预先知道 4 个角点坐标（可通过特征检测或手动标定获得）。

---

### 29. 矩形裁剪（RectROI）

| 属性 | 说明 |
|------|------|
| 节点名 | 矩形裁剪 |
| 参数 | `x`, `y`, `width`, `height` |
| 默认值 | (0,0) 起点，200×200 区域 |

**使用场景**：从大图中裁出感兴趣区域（ROI），减少无关信息干扰，加速后续处理。

**调参技巧**：
- 坐标超出图像范围时自动截断，不会报错。
- 配合模板匹配：先匹配定位 → 获取坐标 → 矩形裁剪 → 详细分析。

## 十一、典型流程示例

### 流程 A：零件计数

```
图像源 → 灰度转换(可选) → 二值化(Otsu) → 开运算(去噪) 
       → 连通区域 → 图像显示
```

### 流程 B：缺陷检测

```
图像源 → 高斯模糊(k=5) → Canny边缘(t1=50,t2=150) 
       → 形态学闭运算(连接边缘) → 连通区域 → 图像显示
```

### 流程 C：颜色定位

```
图像源 → 颜色提取(H:35~85 绿色) → 二值化 → 连通区域 
       → 图像显示
```

### 流程 D：模板定位 + 裁剪分析

```
图像源(主图) ─┐
               ├→ 模板匹配(CcoeffNormed) → 矩形裁剪(匹配坐标) 
图像源(模板) ─┘                              ↓
                                        详细分析(测量/检测)
```

### 流程 E：粘连物体分离

```
图像源 → 中值滤波(去椒盐) → 二值化(Otsu) → 开运算 
       → 距离变换 → 分水岭分割 → 连通区域 → 图像显示
```

### 流程 F：光照补偿 + 边缘检测

```
图像源 → CLAHE均衡(clipLimit=2.0) → 双边滤波(保边去噪) 
       → Canny边缘 → 图像显示
```

---

> **通用建议**：
> 1. 始终从降噪开始（高斯模糊/中值滤波/双边滤波）。
> 2. 二值化/边缘检测前确保光照均匀（CLAHE 或伽马校正）。
> 3. 形态学操作是二值图后处理的"瑞士军刀"。
> 4. 调参时逐个参数调整，观察每次变化，避免同时修改多个参数。
